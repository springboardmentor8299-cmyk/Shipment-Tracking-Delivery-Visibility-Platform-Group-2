# ShipTrack-Pro

Full-stack shipment tracking application with JWT-based authentication, role-based access (USER / ADMIN), real-time tracking, and admin analytics.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 19, Vite 8, Bootstrap 5, Chart.js, Axios |
| Backend | Spring Boot 3.5.3, Java 21, Maven |
| Database | PostgreSQL |
| Auth | JWT (jjwt 0.12.7) |

## Prerequisites

- Java 21+
- Node.js 18+
- PostgreSQL
- Maven 3.9+ (or use the included `mvnw` wrapper)
